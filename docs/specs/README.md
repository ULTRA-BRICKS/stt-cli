# Specifications

Durable contracts for stt's user-facing behaviour: what is shipped, what is a gap, and which ticket owns each gap. Change the spec in the same pull request that changes the behaviour.

- [live-dictation-ux.md](live-dictation-ux.md) — `stt mic`: hotkey bindings and their validators, stopping, the check banner, the default-on daemon, the status line.
- [dictionaries.md](dictionaries.md) — the dictionary marketplace: distributable format, catalog, install, effective glossary and cache fingerprint, overlays, the website, usage-based suggestions.
